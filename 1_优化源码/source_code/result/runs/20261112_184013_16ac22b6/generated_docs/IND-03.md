# 数字孪生：电脑里的分身怎样帮助维护现实设备

## 引言

设备在运行，计算机里的模型也随之更新，这样的模型能帮助人们发现故障、调整生产吗？数字孪生正在探索这类用途。可以把它理解为与实际对象对应、利用对象数据更新的数字模型。构建系统时，需要先明确要映射哪些物理对象，再让相关数据能够被采集，并实时同步到数字模型中。

这篇综述讨论了数字孪生的基础概念、发展过程及研究机会，并重点分析《Computers in Industry》的相关研究。其综合判断是：数字孪生在工业监测、生产优化和资源协调中显示出潜力，但从局部应用走向复杂现场，仍受数据质量、模型准确性和系统集成能力限制。

这篇综述既回顾数字孪生的概念与发展，也按制造、建筑、交通运输，以及技术与范式四个领域梳理相关研究，以识别研究空白。

数字孪生的价值，首先取决于模型是否足够准确。综述指出，输入数据质量、模型的精细程度和计算能力都会影响准确性。建立模型需要汇集多种来源的数据，并在整合前进行清洗和预处理，减少偏差与异常值的影响。模型建立后，还需要进行一致性测试，排除潜在冲突，检查其是否符合实际要求。

制造业中的研究说明了这种潜力及其边界。一项面向航空制造的机床实时监控平台，在真实加工环境中展示了有效表现；它的规模扩展能力则通过模拟测试展示。现场运行与模拟扩展提供的是不同层面的证据，模拟结果不能直接说明平台已在更大规模现场完成验证。

另一项滚动轴承故障检测研究，只使用健康状态数据建立方法，缓解了故障标签稀缺的问题——也就是可用于训练的、已标明故障类别的数据不足。但综述指出，该方法在噪声条件或实时环境中的表现仍待验证。

一项连续制造研究利用物理规律帮助建立数字孪生模型，用于优化工艺设置，却主要关注稳态行为，即过程状态相对稳定的情况。其结果的适用范围也受这一条件限制。综述认为，现有制造业研究多集中于生产过程的单个阶段或有限区域，跨制造过程、跨行业的推广能力仍需检验。

建筑领域的研究在结构监测、人机协作和模块化集成方面显示出潜力，可支持复杂环境中的安全、自动化和资源管理。模块化集成是把不同功能部分组合起来使用。

桥梁监测是一个例子。有研究把增强现实与扫描生成建筑信息模型的方法结合起来：前者把数字信息叠加到现实场景中，后者把扫描结果转为描述建筑对象的信息模型。该平台用于实时评估桥梁损伤、更新模型，支持结构监测和决策。

但平台高度依赖数据质量，如何处理不完整或低质量扫描数据仍需探索，其在更复杂桥梁和基础设施环境中的扩展能力与适应性也尚待验证。建筑领域多数研究依赖高质量数据和受控场景；数据来源分散、系统不能及时交换并使用彼此的数据，以及大型项目实证验证不足，都会影响应用扩展。

交通领域的研究涉及预测性维护、智能检测和物流协调。预测性维护是利用分析与预测来支持维护安排。这些工作显示出改善运营效率和资产可靠性的潜力，但相关研究依赖理想数据条件和有限规模验证。进入复杂、不断变化的交通系统后，带有噪声或数量稀少的数据，以及系统之间的配合，仍是难题。

在大规模物流中，还需要同时处理来源和格式不同的大量数据，并让数据含义的处理与决策保持实时一致。接入更多数据，并不自动意味着决策更及时。

综述将未来研究机会归为生命周期管理、跨学科整合、人机协作，以及数字孪生驱动的智能产业四类。其中，一个重要方向是让数字孪生覆盖产品的整个生命周期，也就是从设计、制造到运行的连续过程。目前多数研究主要服务于单一功能或阶段。

不同阶段的任务有所区别：设计阶段可在虚拟环境中测试和调整参数；制造阶段侧重资源管理和生产流程优化；运行阶段则通过实时监测、数据分析和预测性维护支持质量与可靠性。把这些用途连接起来，需要解决跨系统的数据一致性与协作问题。

人的参与也增加了建模难度。在人机协作系统中，人既是系统组成部分，也会带来不确定性。模型需要考虑人的行为差异，并捕捉其决策和行动，才能提高准确性与灵活性。

综述因此强调工程、计算机科学和管理学之间的协作：系统设计、算法开发、组织实施和战略协调需要共同推进。与此同时，多子系统和设备集成对响应速度的影响，尤其是复杂工业环境中的实时表现，仍未得到充分研究。

## 总结

这篇综述展示了数字孪生在工业中的多种用途，也给出了判断应用效果的关键边界：模型是否准确，数据是否可靠，验证是在模拟环境还是实际现场，以及结果能否扩展到其他过程和更大规模。其结论应放在特定发表时间、筛选条件和重点期刊的证据范围内理解。现有研究显示出应用潜力；走向跨阶段、跨系统的应用，还需要在复杂数据和真实运行条件下积累证据。
