## 2. 判定与阈值

常量只定义在 extract.py：`MIN_TEXT_CHARS=200`、`TABLE_NUMERIC_RATIO=0.30`、
`FIGURE_AREA_RATIO=0.15`，依次判定，边界不改：

1. 清洗后字符数 `<200`：scan_page。
2. 数字字符数/清洗后文本字符数 `>0.30`：table_page。
3. 原始文本包含 `[=∑√∫±^_]`：formula_page。
4. 图像放置面积/mediabox 页面积 `>0.15`：text_page_with_figure。
5. 其余为 text_page。

reasons 按固定顺序记录 text_chars、numeric_ratio、formula_marker、image_area_ratio；
浮点保留三位。图像面积按 PDF 内容流的 cm 变换行列式计算实际放置面积，支持 q/Q
状态恢复、内联图像和嵌套 Form Matrix，不将像素面积误当作 PDF 点面积。
取不到面积时使用 0.0，并明确追加 `image_area=unknown`；文本提取异常则显式
PDF_RENDER_FAILED，不冒充空白扫描页。

清洗归一 ﬁ/ﬂ/ﬀ/ﬃ/ﬄ，合并连续至少三个由空白分隔的单字符，拼接行尾断词；
非断词换行保留，行内连续空白折叠、每行去首尾空白。该换行口径用于让
page_text 与逐行 blocks 一致；空行不生成块，B001 起连续编号，region 为 null。

数字 token 使用卡面正则 `-?\d+(?:[.,]\d+)?%?`，去逗号后排序；冲突数定义为
文本层与视觉文字 token 集合的对称差大小，重复次数不计。比较不含页号、ID、坐标。
有差异时使用既有 `NUMBER_MISMATCH` warning，并在 reasons 写 `numeric_conflicts=N`；
差异不超过三处保留视觉结果，超过三处写 `vision_rejected=数字冲突N处`，
recognition 使用整页文本 blocks，拒绝该页的专用视觉产物。模型输出必须先通过 schema、
页号及表格矩形检查，不能借数字回退掩盖结构错误。

## 5. 风险与未覆盖项

1. tables/figures/formulas 尚未被 evidence 或 writer 消费，本卡不接下游。
2. 图像面积取不到时按卡降为 0.0，并以 image_area=unknown 留痕；这种页可能漏触发
   figure。面积估算不去重叠、不扣裁剪，不识别仅由矢量路径组成而无图像块的图。
3. 数字比较按卡为“专用视觉局部内容 vs 整页文本集合”，正文其他数字可能造成对正确
   局部结果的拒绝。无文本参考的扫描页若视觉输出包含超过三种数字，会回退空 blocks；
   此路径已有测试与 warning，不自行更改卡面规则、阈值或伪造文本。
4. 指定数字正则不完整支持多个千分位或同时含千分位和小数点的数字；保持卡面规则，
   不自行扩大数值规范化范围。公式转写不同记法同样可能产生 warning。
5. 分类优先级每页只选一种视觉任务，同页兼有表/公式/图时不同时调用多种提示词。
6. load_pdf 仍渲染全部页面；本文本优先优化减少模型调用，不改变已有渲染约束。
   CLI 的配置/密钥校验仍由既有 settings/main 决定，本卡没有改为免密钥入口。
7. 未运行 normalize/evidence/write/repair 的真实联网全链路，不声称专用视觉输出科学
   质量已验收。接口正式双签仍待补，不代任何一方签字。

## 6. 下游需知

`page_plan.json` 是“为什么调了模型”的唯一决策证据；用其中的 kind、完整指标 reasons、
numeric_conflicts 和 vision_rejected 解释路由，实际调用次数核对 manifest 中
recognize.model_calls。不要把固定五页、资产存在或 prompt 已加载当作发生过调用。

page_text.json 每页为 page_number/text/chars；recognition 仍是既有 pages/blocks 结构，
页号无缺失无重复。正文及专用视觉页的 blocks 来自清洗后的文本层，region 为 null；
通过校验及数字门限的扫描页才直接采用视觉 blocks。

三份专用产物只在对应页的视觉结果未被拒绝时写入，结构为 `{"pages":[逐页模型对象]}`，
每个页对象分别通过对应新 schema；空 tables/figures/formulas 数组是 schema 允许的
显式输出。拒绝页不进入专用文件，原始真实模型响应由既有 adapter 留存。
它们只登记 artifacts，不能据其缺失判 recognize 失败，也不能假定下游已使用。
