## 4. 输入变化阻塞与方案

```text

SystemExit(2)
XFAIL tests/test_engineering_faults.py::test_input_change_requires_missing_run_reuse_entrypoint - 无 --run-id/断点重跑，A14b blocker
```

strict=True、raises=SystemExit，直接探测真实解析器。该条没有输入变化业务 code，不把 exit2
或 xfailed 说成检测通过，也未使用 skip/assert False。未来 run --run-id 支持后会 strict XPASS，
必须替换为真实哈希校验用例。解除条件是契约决定：是否引入 run_id 复用或输入哈希校验。

两个待决最小方案，本卡不实施：
1. validate --run-id ID --pdf PATH：显式 PDF 与原 manifest input.sha256 比对；I2 布局不变、
   I8 原哈希只读，需决定缺失/不符 code 和退出码。
2. run --run-id ID：任何产物写入前核对材料与哈希；I2 需要约定旧产物/raw 留存，
   I8 需要定义重跑历史和状态，并涉及 I1 入口语义。
