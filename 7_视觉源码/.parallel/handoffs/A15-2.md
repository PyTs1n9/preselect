## 2. 实现行为

`validate.py` 将既有密钥正则抽为公开 `scan_credential_shaped(text) -> bool`。
`_check_sensitive` 改用该函数，`SECRET_LEAK` 的 code、message 和 hint 保持不变；
没有扩大原有正则范围。

`packaging.py` 在 `collect_entries(runs)` 返回三项固定包文件后、写 ZIP 前，扫描其中的
`manifest.json` 和 `validation.json` 原始字节。读取使用 UTF-8 `surrogateescape`，只扫 JSON
文本，不扫 final、PDF 或二进制。命中固定抛出 `PackageFailure`（`IO_FAILURE`/exit 7）：

```text
manifest.json: Credential-shaped text detected
validation.json: Credential-shaped text detected
```

错误只包含文件名和固定文案，不回显密钥。扫描发生在 ZIP 和 package_report 写入前，因此命中
时两者及 `.package-*.tmp` 均不存在。package_report 本身仍未扫描，属于本卡明确未覆盖项。

## 4. 扫描边界

- `sk-*`、非空 `token =`、非空 `bearer` 和 assignment 形式的真实值会拦截。
- `"api_key": "***"`、`api_key=***` 不拦截；这是固定脱敏形态，不新增白名单。
- `max_tokens=100` 不拦截，因为它不是原正则中的凭据字段。
- 不读取 `.env` 或环境变量，不扫描 PDF、final.md、package_report.json 或 ZIP 二进制。
- 既有 `validate_run` 的 SECRET_LEAK 范围不变；package 扫描只增加包内两个 JSON 的前置门禁。

## 5. 失败与产物语义

扫描命中、JSON 原始字节不可读或解码失败均在写 ZIP 前显式返回 `PackageFailure`/exit 7，
不静默放行，不生成 ZIP/report。既有 validation、manifest、stage 和 replay 门禁顺序保持；
未改变 package_report 位置，仍是待裁决设计。
