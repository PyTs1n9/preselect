## 2. 五项检查与统计口径

MATERIAL_MISMATCH 校验 final 优先、缺失才回退 draft 的首个非空行材料注释，ID 限
`[A-Za-z0-9._-]+`，与 evidence 比较。仅此检查读可选 manifest：不存在不报错，存在时核对 ID；
损坏、不可读、重复键或缺合法 ID 报固定 SCHEMA_INVALID。缺输入不以空对象冒充。

正文范围限引言、正文、总结及子节，排除来源整棵子树、标题、其他章节、注释、代码和链接目标。
引用格式为 `[F[0-9]{3,}]`，未知 ID 每个 ID 报一条 CITE_NOT_IN_EVIDENCE，固定路径 final.md#cite；
核心事实未被正文引用则每 fact 报一条 EVIDENCE_UNREFERENCED。来源引用不能补足正文引用。

按 `。！？；` 和换行切句，标点后仅隔空白的引用归前一句。只检查含有效已知引用的句子，
去除引用标记后提取数值。Decimal 对完整数值比较，支持负数、小数、合法千分位、科学计数；
区间只比较显式端点，不推导中间值，不做百分比/单位换算。候选来自本句所引事实的 value 和
value_text。只有未知引用时由 CITE 报错，不进行数值检查。未匹配数字各报 NUMBER_MISMATCH。

匹配数字后检查相应 unit，null 免检；单位须紧随或仅隔空白，完整且区分大小写，m 不可由 mg
满足。多值可共享字符串单位，数组单位按索引对应，长度不等报 SCHEMA_INVALID；区间允许尾部
共享单位。数值已匹配但单位不匹配只报 UNIT_MISSING。单位内部指数不能成为独立事实值。

五项均为 error，消息固定，不回显原文、数值、ID 或 quote。citations 是成功解析的引用出现
次数，重复计、未知不计；unreferenced_evidence 是未引核心事实数；evidence_count 仍为 0/1。
五项已接入 enabled，skipped=[]；缺资产仍以 ASSET_MISSING 显式失败。
