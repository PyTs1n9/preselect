# 真实模型输出后的人工修订

原始模型输出保存在 ../api_run；四份原始输出对应的请求与响应、原文哈希和输出哈希保存在 ../run_logs。根目录的四篇文章是本次评分用的修订版。所有改动保留科学含义，未向文章加入原文之外的新结论。

| 材料 | 人工修订 |
| --- | --- |
| AI-01 | 将错误的“原文标题：材料未提供”改为原论文标题、作者和期刊信息；用原文报告的21人、150条人工标注事实陈述，替换不利于普通读者理解的文本长度统计。 |
| BIO-02 | 给“佐剂作用”增加易懂的提醒类比，同时明确免疫刺激并非越强越好。 |
| IND-03 | 删除误入读者正文的内部证据卡编号；增加机床状态记录的具体例子，并明确异常读数不能单独确诊故障。 |
| MED-04 | 将几处“所给材料”改为自然的文章叙述，保持观点文章与临床试验的区别。 |

以上四篇均由程序通过实际模型接口生成起点，之后经过人工编辑。重跑模型不能保证逐字相同；原始输出、运行日志和本修订记录共同说明实际生成与修改过程。
